# OLED 模块

支持 SSD1306 128x64 I2C 屏。`OLED_Register()` 接收应用配置，内部创建 I2C
设备实例；注册失败返回 NULL。`OLED_Init()` 检查屏幕应答，发送配置并清屏点亮。

显存采用 `gram[8][128]` 页布局，每个字节存储同一列的 8 个纵向像素。
`OLED_Refresh()` 逐页发送，任一次通信失败立即返回 false。

绘图函数只操作显存，ASCII 字体固定为 8x16；无效字符忽略，屏幕外像素裁剪。
`OLED_Show_Num()` 支持 1~10 位，固定宽度补零，超过宽度时保留低位。

这个文件夹负责“如何控制屏幕”，不决定使用 I2C1、地址 0x3C 或显示的文字。
本例程显示内容在 `APP/app_oled.c`，设备配置在 `APP/app_init.c`。
